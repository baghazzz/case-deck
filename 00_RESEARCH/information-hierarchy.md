# Information hierarchy

● Observed · ◐ Strong inference · ○ Reconstruction · ◇ Original interpretation

| Level | Role | Description |
|---|---|---|
| Level 1 | Visual hook | The image, video or likeness that stops the scroll. |
| Level 2 | Headline / core proposition | One sentence that stands on its own. |
| Level 3 | Supporting context | Kicker, reason line, dek, or context (weather, occasion). |
| Level 4 | Metadata | Source · time · price · freshness, one line, tabular. |
| Level 5 | Action | One primary, or the card itself as the tap target. |

## How it changes by content type

| Type | L1 hook | L2 headline | L3 context | L4 metadata | L5 action |
|---|---|---|---|---|---|
| Entertainment | Video frame / live moment | Title of the moment | Who, where, live count | Live badge · viewers · duration | Play / set reminder |
| News | Photo or 9:16 story | Stand-alone headline | 2-line summary | Source · category · time ago | Read full story |
| Commerce | Product or look (starring you) | Product name / look title | Occasion · fit confidence | Price · was · off · price checked | Buy on store / save |
| Sports | Match graphic / field | Score or state ('needs 12 off 6') | Teams, venue | Live · over · time | Follow / watch |
| Utility | Icon + value (31°, ₹4,120) | The change ('dropped to ₹4,120') | What it affects | Source · checked HH:MM | See details |
| Recommendations | Media | Title | Reason line (iris) | Count · from-price | Open; tune (more / less / why) |

## Scanning model
On a hook: image → headline → action (a Z that ends on the button). On a feed: vertical F down the left edge (kickers, titles) with
horizontal excursions into rails. On detail: headline → byline → first paragraph → sticky action. ◐ inferred from the observed formats;
the order is enforced by type size and position rather than colour.
