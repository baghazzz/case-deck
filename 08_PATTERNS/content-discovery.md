# Content discovery

● Observed · ◐ Strong inference · ○ Reconstruction · ◇ Original interpretation — pattern flows are ○ reconstructions built on observed behaviour.

```
Open  →  Scan  →  Discover  →  Engage  →  Deep dive
```

| | |
|---|---|
| **User goal** | Find something worth attention without searching. |
| **Trigger** | Waking the phone, opening the app, or pulling to refresh. |
| **UI structure** | Hook (Card A) → category tabs → reason rail (E) → trending (C) → category tiles. |
| **Interaction** | Swipe/scroll to skip, tap to open, long-press to tune. |
| **Success condition** | User opens a detail page or saves an item within the session. |

## State transitions
1. Open: hero chosen by time + context
2. Scan: vertical scroll, horizontal rails
3. Discover: reason line catches attention
4. Engage: tap → shared-media transition
5. Deep dive: detail with one sticky action
